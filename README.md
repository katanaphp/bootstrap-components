# Bootstrap Components

[![Tests](https://github.com/katanaphp/bootstrap-components/actions/workflows/tests.yml/badge.svg)](https://github.com/katanaphp/bootstrap-components/actions/workflows/tests.yml)

A collection of Bootstrap Blade components for any PHP project using `katanaphp/blade`.

This project is an exploration of implementing reusable, framework-agnostic Blade components outside of Laravel, providing a clean and familiar component API for Bootstrap-based interfaces.
